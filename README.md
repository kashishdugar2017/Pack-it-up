# Pack it up

A visual packing simulator to plan what you are going to pack without clothes lying on the floor

## What it does

  - 46 photos of my own stuff
  - Click an item. Click a organizer. - Packed!!
  - Click a orginizer.Click a bag. - Packed!
  - Live packing list in center

## Run it

  - pip install Pillow
  - python main.py
